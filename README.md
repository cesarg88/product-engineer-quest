# The Product Engineer Quest

The Product Engineer Quest, or PEQ, is a structured professional learning path designed to help software engineers evolve into Product Engineers.

PEQ is currently being validated through a single-player implementation before being generalized.

## Status

PEQ is currently in v0.1.

The first version is being designed for one initial player: César González, a Senior iOS Engineer aiming to strengthen Product Thinking, Business Thinking, Product Execution, Leadership Without Authority, and AI-native Engineering.

## Current Focus

Milestone 1: Think Like a Product Engineer

## Current Goal

Learn through short, concrete milestones with fast feedback and visible evidence.

The current priority is not to build a game system, website, dashboard, or automation.

The current priority is to practice product-oriented thinking and produce evidence of competence.

## Core Idea

PEQ is not a traditional course, bootcamp, or rigid roadmap.

It is a lightweight learning path based on milestones, practice exercises, feedback, evidence, and real professional deliverables.

## Repository Structure

- `docs/`: learning path, milestones, and core methodology.
- `journal/`: product analyses, weekly reviews, RFCs, decision notes, and AI experiments.
- `backlog/`: ideas for future versions.
- `website/`: future static documentation site, intentionally not started yet.
