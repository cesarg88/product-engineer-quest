# The Product Engineer Quest

The Product Engineer Quest, or PEQ, is a structured RPG-inspired professional development system designed to help software engineers evolve into Product Engineers.

## Status

PEQ is currently in v0.1.

The first version is being designed for one initial player: César González, a Senior iOS Engineer aiming to strengthen Product Thinking, Business Thinking, Product Leadership, and AI-native Engineering.

## Current Season

Season 1: From Builder to Product Thinker

## Current Goal

Build the foundations of the PEQ system before creating the website or automating progress tracking.

## Core Idea

PEQ is not a traditional course, bootcamp, or rigid roadmap.

It is a progression system based on quests, skills, XP, evidence, reflection, and real professional deliverables.

## Repository Structure

- `docs/`: core methodology and system definition.
- `journal/`: weekly reviews, product analyses, RFCs, and AI experiments.
- `backlog/`: ideas for future versions.
- `website/`: future static documentation site.
