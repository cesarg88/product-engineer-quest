# Milestone 2 — From Implementation to Product Decision

## Objective

Learn to translate technical work into product decisions.

## Competencies Trained

Primary:

- Product Thinking
- Business Thinking

Secondary:

- Leadership Without Authority

## Why This Matters

Many engineering tasks look purely technical, but they often encode product decisions about behavior, expectations, risk, scope, and value.

## Tools Needed

- Real technical tasks
- ChatGPT as PM reviewer
- GitHub repository

## Exercises

Convert 3 implementation tasks into product decision notes.

Suggested tasks:

1. Add Favorites
2. Improve Search
3. Add PickOne Watchlist

For each task, answer:

- What does this look like technically?
- What product decision is it really?
- What user behavior are we trying to influence?
- What risks or trade-offs exist?
- What is the simplest useful version?

## Deliverables

- `journal/decision-notes/01-add-favorites.md`
- `journal/decision-notes/02-improve-search.md`
- `journal/decision-notes/03-pickone-watchlist.md`

## Completion Criteria

This milestone is complete when the player can explain a technical task to a PM without starting from implementation details.

## Feedback Loop

Each decision note receives feedback on clarity, product framing, trade-offs, and recommendation quality.
