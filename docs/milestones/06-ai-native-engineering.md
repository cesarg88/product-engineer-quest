# Milestone 6 — AI-native Engineering

## Objective

Learn to use AI as a professional multiplier for product and engineering judgment, not only for faster code generation.

## Competencies Trained

Primary:

- AI-native Engineering

Secondary:

- Product Thinking
- Leadership Without Authority

## Why This Matters

Modern product companies increasingly expect engineers to use AI to improve quality, speed, exploration, communication, and decision-making.

## Tools Needed

- ChatGPT
- Cursor, Copilot, Claude, or Codex when useful
- Real PEQ artifacts

## Exercises

Create 5 reusable AI workflows:

1. AI as PM reviewer
2. AI as skeptical designer
3. AI as CTO reviewing trade-offs
4. AI as data analyst suggesting metrics
5. AI as interviewer

Each workflow should include:

- purpose;
- prompt;
- example use;
- useful output;
- limitations;
- human judgment required.

## Deliverables

- `journal/ai-workflows/product-engineer-workflows.md`

## Completion Criteria

This milestone is complete when the player has reusable prompts/workflows that improve real product-engineering work.

## Feedback Loop

Each workflow receives feedback on usefulness, reliability, limitations, and transferability to real work.
