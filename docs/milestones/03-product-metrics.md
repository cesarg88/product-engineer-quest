# Milestone 3 — Product Metrics

## Objective

Learn to choose useful product metrics without overcomplicating analysis.

## Competencies Trained

Primary:

- Product Thinking
- Business Thinking

## Why This Matters

A Product Engineer should distinguish between a feature being used and a feature creating value.

Metrics help connect product decisions to user behavior and business outcomes.

## Tools Needed

- Product examples
- ChatGPT as data/product reviewer
- GitHub repository

## Exercises

For 5 features, define:

- primary metric;
- secondary metrics;
- counter-metric;
- why those metrics matter.

Suggested features:

1. Fever Favorites
2. Fever Search
3. Fever Feed
4. Qonto onboarding
5. PickOne Watchlist

## Deliverables

- `journal/metrics/feature-metrics.md`

## Completion Criteria

This milestone is complete when the player can explain:

- what metric shows usage;
- what metric shows value;
- what metric protects against a bad side effect.

## Feedback Loop

Each metric set receives feedback on whether it is actionable, relevant, and connected to the product hypothesis.
